Optional: your own background music.

Put an mp3 here named  music.mp3  and the game plays it (looping) instead of the generated music.
Delete the file to go back to the generated music.

Optional: thunder.mp3 here is played in a loop (quietly) during storms, on top of the synthesised
thunder that goes with each lightning flash.

Everything else (engine, water, rain, lamp, anchor, horn, bump) is synthesised in the browser,
see src/audio/audio.js.
